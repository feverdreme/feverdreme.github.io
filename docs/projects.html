x86ISTMB ↗

An optimizing compiler from a custom programming language to x86, developed as a five-person CS 3110 project. My work covered the parser, lexer, abstract syntax tree, and type checking.

OCaml · Compiler construction · Team project

Ballroom Rounds Maker ↗

An OCaml tool for preparing ballroom competition rounds from individual songs. The audio pipeline trims songs, adds fades and silence breaks, and produces a single MP3. Terminal and Bonsai web editors support creating, reordering, and saving round descriptions.

OCaml · Bonsai · ffmpeg · Audio tooling

Paradigm-agnostic code embeddings ↗

A group computational linguistics project replicating language-agnostic code embedding experiments and proposing an extension to programming paradigms. I contributed a CodeSearchNet data loader and normalized mean reciprocal rank evaluation.

Python · Code representations · Research course

CU AUV: Modern Practices and Type Integration

A prototype migration of Cornell’s autonomous underwater vehicle vision and mission code toward modern Python type annotations and language features. My semester report describes the implementation and remaining integration work.
