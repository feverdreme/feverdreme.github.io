Research

CurrentFall 2026

Proof synthesis & program specifications

Cornell University · Advisor: Alexandra Silva

I’m exploring how AI can help learn program specifications, with a focus on Outcome Logic. My current work is a literature review of the logic and automated techniques for reasoning about program behavior.

2024–2025

Dynamic scheduling for type inference

Cornell University · Advisors: Nate Foster & Jules Jacobs

I researched how dynamically scheduling type inference constraints can generalize the heuristics used by Quick Look and FreezeML. I implemented the approach for System F and a dependently typed core calculus, and evaluated it using the Quick Look benchmark.

Spring 2026

Latent reasoning

Cornell University · Advisor: Daniel Halpern-Leistner

I built infrastructure for recurrent distillation: a prototype student model, a pipeline for extracting teacher-model hidden-state reasoning traces, and a Sudoku trace dataset for pre-training experiments.

Spring 2026

Interpreting authorship representations

Cornell University · Advisor: Claire Cardie

I worked on the interpretability of universal authorship representations, testing an existing benchmark on larger models using the project’s evaluation infrastructure.

Fall 2024

Language-agnostic code embeddings

Cornell University · Research course with Marten van Schijndel

In a group project, I replicated experiments from Utpala et al. (2023) on how models represent code across programming languages. We also explored extending the analysis to programming paradigms. My code contributions include a CodeSearchNet loader and normalized mean reciprocal rank evaluation.
